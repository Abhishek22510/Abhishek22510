<h3 align="left">Featured project:</h3>

### NetSentry— Network Traffic & Anomaly Detection Dashboard

An offline SOC investigation tool built with Python and Streamlit that:

- Parses PCAP and PCAPNG files safely using Scapy.

- Extracts packet, IP, port, TCP flag, and DNS metadata.

- Analyzes TCP, UDP, ICMP, DNS, conversations, and traffic volume.

- Detects possible port scans, high SYN activity, ICMP bursts, DNS spikes, long DNS queries, unusual ports, high traffic volume, and high TCP reset ratios.

- Provides searchable investigation pages and severity-based alert triage.

- Generates PDF, JSON, and CSV investigation reports.
